泰合礼 THL 礼金簿 · 安卓手机使用说明
========================================
品牌：泰合礼
口号：泰然存礼，和合记情

【最简单的用法：不安装，直接打开】
1. 将 泰合礼-礼金簿.html 发送到安卓手机（微信文件助手、USB、网盘都行）。
2. 把文件保存到手机的“文件/下载”目录。
3. 用 Chrome 浏览器打开这个 HTML 文件。
   - 如果文件管理器直接打开了网页预览，请选择“用其他应用打开 → Chrome”。
   - 也可以把文件放到 Download 目录，在 Chrome 地址栏输入：
     file:///sdcard/Download/泰合礼-礼金簿.html
4. 打开后点 Chrome 右上角菜单 →“添加到主屏幕”，下次从桌面进入。
5. 所有数据保存在本机浏览器里。请勿清理 Chrome 的网站数据；换手机前先导出备份。

【推荐用法：安装成真正的 PWA App】
需要把整个项目文件夹上传到支持 HTTPS 的静态托管：
- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
- 自己的 HTTPS 网站
然后用安卓 Chrome 打开，右上角菜单 →“安装应用”或“添加到主屏幕”。
安装后可离线使用，并支持系统通知、通讯录选择等安卓浏览器能力。

电脑本地预览：
在文件夹中执行：
  python -m http.server 8080
电脑打开 http://localhost:8080
（局域网 HTTP 可以试用，但不能安装 PWA）

【第一次使用建议】
1. 点“创建第一本礼簿”，填写婚礼/寿宴/乔迁等标题、日期、地点、主人。
2. 点“登记礼金”，填写姓名、金额；可点选常用金额、添加关系、拍照存证。
3. 用“保存并继续”连续录入宾客。
4. 在“统计”查看总额、人数、排行和关系占比。
5. 在“人情”维护宾客档案与双向人情。
6. 结束后进入“导出/分享”：Excel、图片、打印、只读分享。
7. 定期进入“设置 → 数据安全 → 导出完整备份”。

【重要提示】
- 密码锁只保护界面访问，不加密数据；请同时开启手机锁屏。
- 照片保存在本机 IndexedDB，备份 JSON 会自动包含照片。
- 自动恢复点不含照片，不能替代完整 JSON 备份。
- 清理浏览器缓存/无痕模式/更换手机可能导致本机数据丢失。
- 只读分享生成的是离线 HTML 文件，不是实时协作链接。
- 通讯录导入、系统通知、PWA 安装需要安卓 Chrome + HTTPS/安装版。
- 关掉 App 后仍要收到提醒，请使用“导出到手机日历”（.ics）。
- 微信内直接打开 HTML 可能受限，收到只读礼簿后请选择“用浏览器打开”。

【数据文件说明】
- 泰合礼-礼金簿.html：离线单文件版，所有功能不联网。
- index.html + css/js/assets：PWA 源文件，适合部署到 HTTPS。
- manifest.webmanifest / sw.js：安装与离线缓存。
- 每次导出生成的文件（.xlsx / .png / .html / .json / .ics）都在手机下载目录。
